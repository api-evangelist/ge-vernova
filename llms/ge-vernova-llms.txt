# GE Vernova

> GE Vernova is an energy company spun out of General Electric in April 2024, bringing together the
> former GE Power, Renewable Energy, Digital and Energy Financial Services businesses. Its software
> arm — GE Vernova Electrification Software, the former GE Digital — is where the APIs are: Proficy
> industrial software (Historian, Plant Applications MES, Operations Hub, CSense, iFIX, CIMPLICITY),
> Asset Performance Management (Meridium, SmartSignal), and GridOS for transmission and distribution.
> Every one of these APIs runs on infrastructure the CUSTOMER operates — an installed Proficy server
> or a tenanted APM environment — so there is no vendor-hosted base URL to call and no public
> machine-readable contract: each product's Swagger UI is served from the customer's own instance.
> The documentation, however, is public and substantial.
>
> Generated by API Evangelist from published GE Vernova documentation, 2026-09-12. No OpenAPI,
> AsyncAPI, MCP server or A2A agent card is published by GE Vernova for any of these products.

## APIs

- [Proficy Historian REST API](https://www.gevernova.com/software/documentation/historian/version2025/c_historian_apis_overview.html): Manage Historian systems, collectors, collector instances, data stores, tags, the Historian model, and alarms and events. Base `https://<historian-web-client-host>/historian-rest-api/v1/`, model service at `/historian-model/v2/`. REST + HATEOAS, JSON, OAuth2 bearer tokens from Proficy Authentication.
- [Proficy Plant Applications REST API](https://www.gevernova.com/software/documentation/proficy-plant-applications/version2025/pa_rest_api/c_rest_api_pa_introduction.html): 37 microservices on port 5059 of the Web Client host — activities, work orders, routes, downtime, OEE, non-conformance, e-signature, ERP import/export and more, each with its own Swagger UI.
- [Proficy Operations Hub integration REST APIs](https://www.gevernova.com/software/documentation/opshub/version2025/windows/r_rest_integration_apis.html): Pull M2M device telemetry and read/write rows in any custom entity. Token login at `/app/iqp/api/rest/login`.
- [Proficy Operations Hub M2M device REST APIs](https://www.gevernova.com/software/documentation/opshub/version2025/windows/r_m2m_device_rest_apis.html): Device-side login / publish / subscribe over REST POST, JSON payloads.
- [APM Data Extraction OData API](https://www.gevernova.com/software/documentation/cloud-apm/latest/ade-supported-features.html): OData service at `{{host}}/meridium/api/odata` with `$metadata`, `$select`, `$filter`, `$top`, `$skip`, `$orderby`, `$expand`, `$count` and server-driven pagination. Requires a Meridium Core (Foundation) licence and a Predix UAA account.
- [APM Simple Ingestion API v2](https://www.gevernova.com/software/documentation/cloud-apm/latest/simple-ingestion-overview-v2.html): Create or update entities, relationships and ACA matrices in APM.

## Specs

No machine-readable API contract is published. Each installed product serves its own Swagger UI:

- Historian: `https://<web-based-client-machine-name>/historian-rest-api/swagger-ui.html`
- Plant Applications: `https://<FQDN-or-Hostname>:5059/<service-name>/swagger-ui/index.html`
- APM OData: `{{host}}/meridium/api/odata/$metadata`

## Events

- [Plant Applications Kafka topic catalogue](https://www.gevernova.com/software/documentation/proficy-plant-applications/version2025/kafka/pa_webclient_Kafkaservices_topics.html): per-service topics (`mes.workorder.workorders.<site-id>`, `mes.erp.outbound.messages.<site-id>`, `mes.comment.commentThreads.<site-id>` …) with documented JSON and B2MML payload structures and a `mes.failedevents.<site-id>` dead-letter topic.
- [Operations Hub MQTT APIs](https://www.gevernova.com/software/documentation/opshub/version2025/windows/r_mqtt_apis.html): MQTT broker client with a defined topic namespace keyed on Cloud ID, Device ID and Instance.
- Historian collectors speak MQTT, MQTT Sparkplug B, OPC UA DA, and OPC Classic DA/HDA/A&E; Historian can act as an OPC UA HDA server.

## Auth

- [Proficy Authentication (UAA)](https://www.gevernova.com/software/documentation/uaa/version2025/index.html): OAuth2 authorization server for the Proficy products. Published scope tables per product — `historian_rest_api.read|write|admin`, `iqp.clouduser`, `mes.<application>.user`, `scada.fix.shared.*`.
- [APM OData authentication](https://www.gevernova.com/software/documentation/cloud-apm/latest/ade-authentication.html): Predix UAA password grant; SSO credentials will not work.
- [Support portal OIDC discovery](https://softwaresupport.gevernova.com/.well-known/openid-configuration): the one `/.well-known/` document GE Vernova serves.
